# Trilium-MarkdownLivePreview
一个用于 Trilium 笔记的插件，可实时预览 Markdown 文件，


## 功能特性

- 实时预览 Markdown 笔记
- 支持全局和单笔记样式
- 可同步的滚动条
- 支持包括表格等功能

## 安装

1. 从 GitHub 的 [最新发布](https://github.com/449128388/Trilium-MarkdownLivePreview 页面下载 `zip` 文件。
2. 将 zip 文件导入到 Trilium 中，但请务必取消勾选 `安全导入`！
3. （可选）创建一个或多个 `CSS` 类型的子代码笔记，并填入任何全局 Markdown 样式。

## 使用说明

创建一个 Markdown 类型的代码笔记之后，只需在代码编辑器侧用 Markdown 编写内容。你会看到预览会随着你的输入实时更新。

### 样式设置

全局样式和本地样式都会在笔记切换时被获取并重新应用，所以如果你在调整样式，无需不断重新加载！
